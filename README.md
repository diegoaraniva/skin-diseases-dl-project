# skin-diseases-dl-project

Proyecto de Deep Learning con dos apps web en Streamlit:
- Un pipeline de entrenamiento que entrena un modelo EfficientNet para clasificacion de imagenes de afecciones en la piel.
- Una demo que consume los artifacts ya entrenados y los descarga desde Google Drive.

El proceso de inferencia para determinar que herramientas son mas eficientes se encuentra en la carpeta notebooks.
